vFlow · 超级岛展开态 UI 规格

已选定 方案 3（进度主导）。本页是实施规格：含浅色／深色两套配色的全部状态， 以及 RemoteViews 实现所需的色值 token。

为什么要两套配色：这套 RemoteViews 不只用于超级岛展开态，还被通知栏与锁屏预览复用—— 后两者有浅色模式。岛展开态本身恒为深色，但同一份布局必须以两种配色交付： miui.focus.rv（浅）与 miui.focus.rvNight（深）。

性能前提：RemoteViews 的收益来自「复用同一实例，只调 setTextViewText 等改变化字段」。 本设计在工作流每推进一步时只改动 3 个字段（大号进度、进度条宽度、当前模块名）； 秒表由 Chronometer 系统自走，不需要为计时重发通知。

进度语义提醒：进度按顶层步骤数计算（(pc * 100) / steps.size）， 不感知 If／Loop 内部步骤。长工作流里若内部循环跑很多步，进度条会长时间静止——这是既有语义， 本设计的大号 3/8 数字可部分补偿（数字本身是准确的「第几个顶层步骤」）。

RemoteViews 白名单：只能使用 LinearLayout / FrameLayout / RelativeLayout / ImageView / TextView / Chronometer / ProgressBar。ConstraintLayout、Space、 自定义 View 会在远端 inflate 失败。根容器不设背景（卡片底由 SystemUI 绘制）。
