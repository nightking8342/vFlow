排序时「分支体」跟不跟着走 这是你问的第一个问题。下面是两种实现的真实对比：先在 sheet 里拖动分支行调换顺序，再切到「错误做法」重跑一遍，看主列表里的普通步骤落在谁名下。

① 按 caseId 找回分支体（本设计）
分支卡片 + 它的整段普通步骤被当成一个整体，按 id 认领。调序 ⇒ 体跟着卡片走；删除 ⇒ 体一起消失。
② 只挪卡片（错误做法）
分支体靠「卡片的位置」隐式定义 ⇒ 只挪卡片、体留在原地，两段体会整体互换。不报错，但你调的是顺序、变的是执行内容。

② 错误：调序后 `"ok"` 名下变成了「输出日志」—— 分支体没跟着走。

提示：删除同理 —— sheet 里删一条分支，它的整段普通步骤一起删掉（不是把这几步让给上一条分支）。 分支卡片上的 🗑 与 sheet 里的 🗑 是同一件事（共用一份删除逻辑），不是两种行为。

已弃的两个方案（留档）方案 A / B 都把「加分支」放到卡片上，但都没有排序入口 —— 而分支列表需要一个能一次看全、能调序的地方。

方案 A · 卡片上一键
卡片操作区一个 ＋，短按加 Case、长按加 Default。
弃因：没有「把这条分支挪到前面」的入口；长按加 Default 也不易发现。
方案 B · 短按弹菜单
＋ 短按弹小菜单（加 Case / 加 Default）。
弃因：同上，仍然没有排序；且要多写一个 PopupWindow。
